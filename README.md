# Signature

This repo contains the `quarto` implementation of the email signature. It generates an `html` file with the correct formatting, including links and icons.
These are in fact stored on the repository as the relevant images (either `png` or `jpeg`) and are linked in the `qmd` document using the format
```
https://raw.githubusercontent.com/giabaio/signature/main/image.ext
```
for each image file with extension `ext`.
